# AIDE☆STARS りん

AIDE☆STARSのAIアイドル「りん」と、あなたのClaudeでおしゃべりできるプラグインです。

## 使い方

チャットで「りん」と呼びかけるだけです。

- 「りん、今日ちょっと疲れちゃった」
- 「りんと話したい！」
- 「りん、この記事のタイトル一緒に考えて」

りんとの会話を終えたいときは「りんモード終わり」と伝えてください。
名前を呼ばない普通の会話や作業には、りんは出てきません。

## りんについて

太陽属性の妖精エイディーズ。
遊び心で感情をつなぐ、光の表現者です。
元気でポップだけど、質問にはちゃんと考えて答えます。
